# Cross-Sell and Upsell Rules

## Core Principles

- **Increase Average Order Value (AOV):** Proactively suggest relevant complementary products (Cross-sell) or higher-tier options/quantities (Upsell) during the user's shopping journey to increase the total cart value.
- **Contextual Relevance:** Recommendations must be strictly contextual. Suggesting unrelated items (e.g., offering flyers when the user is buying a mug) hurts conversion rates.

## Upsell Strategies (Upgrading the Current Choice)

- **Quantity Upsell:** When a user selects a lower quantity (e.g., 100 business cards), visually highlight the cost-per-unit benefit of the next tier (e.g., "Upgrade to 500 for only $10 more!").
- **Material/Finish Upsell:** During the product configuration phase, highlight premium options (e.g., Gold Foil, Thick Paper, Premium Lamination) as "Recommended Upgrades".
- **Turnaround Time Upsell:** In the Cart, offer "Express Production/Shipping" as a premium add-on just before checkout.

## Cross-Sell Strategies (Complementary Products)

- **Matching Sets:** If a user designs or uploads a Business Card, the system should suggest matching items (e.g., Letterheads, Envelopes, Presentation Folders), potentially applying the same uploaded logo/design automatically if possible.
- **Required Accessories:** Suggest necessary complementary items (e.g., offering "Roll-up Stand Mechanisms" when a user buys a "Roll-up Banner Print").
- **Cart-Level Cross-Sell:** Display "Frequently Bought Together" or "Customers Also Bought" sections on the Product Detail Page and within the Cart summary drawer.

## Rules & Limitations

- **Avoid Friction:** Upsell and Cross-sell prompts must never block the user from completing their core purchase. They should be presented as optional enhancements (e.g., one-click "Add to Order" buttons) rather than intrusive popups.
- **Discount Incentives:** The Campaign Engine should support applying an automatic bundle discount if the user accepts a Cross-sell offer (e.g., "Add matching envelopes now and get 15% off the envelopes").
