# Affiliate Program Rules

## Core Principles

- Affiliates generate traffic and sales via unique links or referral codes and earn commissions.
- Tracking must be accurate, resilient, and privacy-compliant (GDPR, CCPA).

## Tracking & Attribution

- Use robust tracking methods (URL parameters, cookies, local storage).
- Define the attribution window (e.g., 30-day cookie life).
- Define attribution model (e.g., Last-click wins).

## Commissions

- Commission can be a flat fee per order or a percentage of the order value.
- Exclude shipping, taxes, and applied discounts from commission calculations.
- Commissions remain "Pending" until the order's return period expires and is marked as "Completed".

## Affiliate Codes

- Affiliates can provide customers with discount codes (e.g., AFF10).
- Using an affiliate code strongly attributes the sale to that affiliate, overriding cookie attribution.

## Payouts

- Maintain a clear ledger of earned, pending, and paid commissions.
- Define minimum payout thresholds (e.g., $50).
- Support generating automated invoices or payout reports.

## Analytics

- Affiliates must have a dashboard to see clicks, conversions, and earnings in real-time.
