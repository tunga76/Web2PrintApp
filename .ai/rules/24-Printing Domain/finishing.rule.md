# Finishing Rules

## Core Principles

- **Post-Press Operations:** Track all operations that occur after printing: Folding (Kırım), Binding (Ciltleme), Die-Cutting (Özel Kesim), Foil Stamping (Yaldız), Embossing (Gofre).
- **Complexity Multipliers:** Finishing options exponentially increase production time and cost. The pricing engine must accommodate fixed setup costs + variable per-unit costs for each finishing operation.
