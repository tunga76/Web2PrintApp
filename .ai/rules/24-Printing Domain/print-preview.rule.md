# Print Preview Rules

## Core Principles

- **WYSIWYG:** Customers must see an accurate, low-resolution RGB preview of their uploaded or designed artwork before adding to cart.
- **Safe Zones:** The preview MUST visually overlay the `Bleed Line` (Taşma), `Trim Line` (Kesim), and `Safe Zone` (Güvenli Alan) to warn users if text is too close to the edge.
