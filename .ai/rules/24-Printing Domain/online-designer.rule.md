# Online Designer Rules

## Core Principles

- **Canvas to Print-Ready:** An integrated HTML5 canvas editor must be capable of exporting high-resolution, 300 DPI, CMYK PDF files suitable for direct-to-press production, not just web images.
- **Template Engine:** Support parametric templates where users can swap out text and images within predefined, constrained bounding boxes.
- **Font Licensing:** Ensure only commercially licensed or open-source fonts (e.g., Google Fonts) are available in the editor to prevent copyright issues during rasterization.
