# Print Pricing Rules

## Core Principles

- **Non-Linear Pricing:** Print pricing is rarely linear. A quantity of 1000 does not cost 10x the price of 100.
- **Cost-Plus vs Grid Pricing:**
  - *Grid Pricing:* The storefront typically uses a pre-calculated multi-dimensional price grid (Quantity x Paper x Finishing) for speed.
  - *Cost-Plus (Dynamic):* For custom sizes, the backend must calculate the sheet layout (Imposition / Montaj) to determine how many items fit on a parent sheet, calculate raw material + click/press costs, and add margin.
- **Setup Fees:** Clearly separate fixed machine setup fees from run/click costs.
