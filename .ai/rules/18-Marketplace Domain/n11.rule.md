# N11 Integration Rules

## Core Principles

- **Provider Documentation:** Confirm listing approval, order eligibility, delivery templates, and commission data against current official documentation and the connected merchant account. Record the documentation URL and verification date; examples below depend on the enabled API workflow.

- **Product Listing:** N11 requires specific approval processes for product listings and category mapping. The integration must handle asynchronous listing status updates (Approved, Rejected, Pending).
- **Template Management:** N11 often uses Delivery Templates and Format Templates. The integration must map internal shipping profiles to N11's pre-defined Delivery Template names.

## Orders & Billing

- **Delayed Import:** N11 holds orders in a pending state until payment is fully verified. The Hub should only import orders once they reach the "Approved" (Onaylandı) state.
- **Commission Handling:** Import commission rates and platform fees (if available via API) into the Order Domain to ensure accurate net revenue reporting in the Hub.
