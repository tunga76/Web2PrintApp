# Navigation Rules

## Core Principles

- **Predictability & Hierarchy:** Navigation menus must follow a logical, predictable hierarchy. The primary navigation should rarely exceed 7 main items (Miller's Law) to avoid cognitive overload.
- **Breadcrumbs:** Deeply nested pages (e.g., `Category > Sub-Category > Product`) MUST feature prominent breadcrumb navigation to allow users to trace their path backward easily.

## Implementation Standards

- **Mega Menus:** For complex catalogs (like Web-to-Print), use Mega Menus to expose sub-categories efficiently without requiring multiple clicks, but ensure they are easily navigable via keyboard.
- **Mobile First:** Mobile navigation (Hamburger menus, bottom tabs) must be touch-friendly, with minimum touch target sizes of 44x44 CSS pixels.
