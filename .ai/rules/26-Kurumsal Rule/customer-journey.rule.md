# Customer Journey Rules

## Core Principles

- **Friction Reduction:** Every step from Landing -> Product Selection -> Configuration -> Cart -> Checkout must be ruthlessly optimized to remove friction. Minimize mandatory form fields.
- **Clear Call to Actions (CTAs):** A page should have one primary, highly visible CTA (e.g., "Add to Cart", "Proceed to Checkout"). Secondary actions should be visually de-emphasized.

## Web-to-Print Specifics

- **Guided Configuration:** For complex print products, the customer journey must guide the user sequentially (e.g., choose Size, then Paper, then Finishing). Do not overwhelm them with all 50 options simultaneously.
- **Save and Resume:** The journey must allow users to save their progress (especially during artwork design/upload) and resume on a different device later.
